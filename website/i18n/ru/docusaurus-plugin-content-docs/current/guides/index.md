# Руководства

Крейт `ruststream-rust-mqtt` реализует брокер MQTT 5 для [RustStream](https://powersemmi.github.io/ruststream/latest/ru/) для рантаймов embassy и compio.

У крейта два варианта.
Вариант для устройства обходится без кучи: плата объявляет память брокера как `static`, а доставка заимствует полезную нагрузку из её буфера приёма.
Вариант с кучей (фича `alloc`, которую включает `compio`) работает поверх клиента [rust-mqtt](https://docs.rs/rust-mqtt) и подходит хосту compio или устройству, у которого есть куча.

Начните с варианта, под который вы собираете сервис: [первый сервис на устройстве](./getting-started-device.md) или [первый сервис на хосте compio](./getting-started-compio.md).
[Тестирование сервиса для устройства](./testing.md) показывает, как запустить любой из них на хосте до того, как он попадёт на плату.
